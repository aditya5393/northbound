# NorthBound

Travel and tour company management: trips, customers, append-only payments ledger, expenses, profit calculation, and printable bills.

## Project Structure
- `index.html`: Complete single-page travel management application.
- `config.js`: Configuration for company info and optional Supabase backend.
- `manifest.json`: Web App Manifest for mobile installation (PWA).
- `sw.js`: Service worker for offline access and caching.
- `icon.png`: App icon for home screen and browser.

## Deployment on Vercel
1. Upload these files directly to the root of your GitHub repository.
2. In Vercel, import your repository and click Deploy.
3. Your app is live immediately!
